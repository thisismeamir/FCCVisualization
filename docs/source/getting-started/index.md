# Getting started

## Build

fccvis needs a C++20 compiler and CMake ≥ 3.20; Catch2 v3 for the tests.
Everything else is optional and switched on when found (see
[dependencies](../release/dependencies.md)).

```text
cmake -S . -B build -G Ninja
cmake --build build
ctest --test-dir build -L core
```

This builds the library, the `fccvis-shell` program, and the dependency-free
parts: the CSV adapter and the raster (PNG), SVG and histogram backends.

The test suite runs this script and checks both its output and the picture,
so this page shows what the current code produces.

## In an interactive ROOT window

With ROOT (Eve) available at build time and an X display, the same scene
opens in the ROOT event display instead of files: replace the two
`backend init` and `open` pairs by

```text
backend init root eve
open eve event
```

You can then rotate and pick in the window; picks are printed by the shell
and camera moves update the session. See {doc}`../backends/root`.

## Next steps

- Move to the next event: `entry event/hits next` and `entry event/tracks next`.
- Select: `where event/hits energy > 0.5 and subdetector == "ECalBarrel"`.
- Look from the side: `camera event dir 1 0 0`.
- Several views: `scene new side`, `layout split(event, side)`.
- Read the {doc}`concepts <../concepts/index>` and the {doc}`shell <../shell/index>` pages.
