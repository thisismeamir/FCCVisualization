\doxysubsection{Detailed Description}
ROOT GUI application lifecycle management. 

Defines the \doxylink{classfccvis_1_1gui_1_1GuiApplication}{fccvis::\+gui::\+\+Gui\+Application} class, which owns and manages the ROOT {\ttfamily TApplication} instance used by the FCCVisualization graphical interface.

The GUI application is associated with an existing \doxylink{classfccvis_1_1session_1_1Session}{fccvis::\+session::\+\+Session} and provides the main event loop and termination interface for the graphical application.
