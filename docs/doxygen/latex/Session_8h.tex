\doxysubsection{Detailed Description}
Session state, input data, and visualization configuration. 

Defines the classes used to represent an FCCVisualization session:
\begin{DoxyItemize}
\item \doxylink{classfccvis_1_1session_1_1SessionOptions}{fccvis::\+session::\+\+Session\+Options} stores visualization configuration.
\item \doxylink{classfccvis_1_1session_1_1SessionData}{fccvis::\+session::\+\+Session\+Data} stores loaded event data.
\item \doxylink{classfccvis_1_1session_1_1Session}{fccvis::\+session::\+\+Session} coordinates the session name, data, options, and access to event information.
\end{DoxyItemize}
