\doxysubsection{Detailed Description}
Event data loaded into a session. 

\doxylink{classfccvis_1_1session_1_1SessionData}{Session\+Data} organizes podio event frames into named categories.

A category contains an ordered sequence of {\ttfamily podio::\+\+Frame} objects. The category name is used to distinguish different data sources or logical groups of events within a session.
