\doxysubsection{Detailed Description}
Command-\/line options for the FCCVisualization application. 

\doxylink{structfccvis_1_1cli_1_1CliOptions}{Cli\+Options} represents the configuration produced by parsing the application\textquotesingle{}s command-\/line arguments.

The options determine which application interface is started and which optional input files are supplied to the session.
