\doxysubsection{Detailed Description}
Visualization and runtime configuration for a session. 

\doxylink{classfccvis_1_1session_1_1SessionOptions}{Session\+Options} describes the objects that configure how a session is visualized. It contains the available cameras, filters, scenes, and scene layout, together with the optional path to a detector geometry description.

The objects referenced by this class are shared through {\ttfamily std::\+shared\+\_\+ptr} because the same visualization object may be referenced by multiple parts of the visualization system.
