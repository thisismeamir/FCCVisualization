\doxysubsection{Detailed Description}
Interactive command-\/line shell for a visualization session. 

\doxylink{classfccvis_1_1cli_1_1InteractiveShell}{Interactive\+Shell} provides a command interface for inspecting and controlling an active \doxylink{classfccvis_1_1session_1_1Session}{fccvis::\+session::\+\+Session}.

The shell maintains command history, provides built-\/in commands for scene management, and exposes the active session to the ROOT Cling interpreter.

The shell uses a \doxylink{classfccvis_1_1backend_1_1root_1_1RootSceneManager}{fccvis::\+backend::\+root::\+\+Root\+Scene\+Manager} to manage the ROOT-\/based visualization of scenes.

\begin{DoxyNote}{Note}
The Session is referenced but not owned by the shell. The referenced session must remain valid for the lifetime of the \doxylink{classfccvis_1_1cli_1_1InteractiveShell}{Interactive\+Shell}.
\end{DoxyNote}
