\doxysubsection{Detailed Description}
Node in the hierarchical layout of visualization scenes. 

A \doxylink{structfccvis_1_1scene_1_1meta_1_1LayoutNode}{Layout\+Node} forms one element of a tree describing how multiple scenes are presented together.

The meaning of the node\textquotesingle{}s other members depends on its kind:


\begin{DoxyItemize}
\item For {\ttfamily \doxylink{namespacefccvis_1_1scene_1_1meta_a017bf030c5651ecea05a747f42afba44a4492081ca02b059f9e8af4ddaf0f7292}{Layout\+Kind::\+\+Pack}}, \doxylink{structfccvis_1_1scene_1_1meta_1_1LayoutNode_a1c51ffbd38dcd79619a36368506c58ac}{orientation} and \doxylink{structfccvis_1_1scene_1_1meta_1_1LayoutNode_a5938a74025c87c462fe1872595c2a915}{children} are used. Child weights determine the relative allocation of space.
\item For {\ttfamily \doxylink{namespacefccvis_1_1scene_1_1meta_a017bf030c5651ecea05a747f42afba44a5c6ba25104401c9ee0650230fc6ba413}{Layout\+Kind::\+\+Tab}}, \doxylink{structfccvis_1_1scene_1_1meta_1_1LayoutNode_a5938a74025c87c462fe1872595c2a915}{children} is used and child weights are ignored.
\item For {\ttfamily \doxylink{namespacefccvis_1_1scene_1_1meta_a017bf030c5651ecea05a747f42afba44ac3b5e1f7de11d645fb1da6c5415b1fa5}{Layout\+Kind::\+\+Leaf}}, \doxylink{structfccvis_1_1scene_1_1meta_1_1LayoutNode_aab75d819120f1784e99c3623b917a4a6}{scene\+Name} identifies the scene materialized by the node.
\end{DoxyItemize}

This structure allows a session to represent nested arrangements, such as horizontal and vertical groups containing tabbed scenes.
