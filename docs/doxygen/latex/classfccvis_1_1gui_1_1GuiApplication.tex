\doxysubsection{Detailed Description}
Manages the ROOT GUI application for FCCVisualization. 

\doxylink{classfccvis_1_1gui_1_1GuiApplication}{Gui\+Application} owns the ROOT {\ttfamily TApplication} instance responsible for managing the graphical application\textquotesingle{}s event loop.

The application operates on an existing \doxylink{classfccvis_1_1session_1_1Session}{fccvis::\+session::\+\+Session}, which is referenced rather than owned by the GUI application. The lifetime of the Session must therefore extend beyond the lifetime of the \doxylink{classfccvis_1_1gui_1_1GuiApplication}{Gui\+Application}.
