\doxysubsection{Detailed Description}
A point-\/like graphical primitive. 

\doxylink{classfccvis_1_1scene_1_1meta_1_1Marker}{Marker} represents a single position in three-\/dimensional space together with its display color and size.

Markers can be used for annotations, reference points, detector features, or other point-\/like visualization elements.
