\doxysubsection{Detailed Description}
Configuration options associated with a visualization scene. 

\doxylink{classfccvis_1_1scene_1_1meta_1_1SceneOptions}{Scene\+Options} represents the extensible configuration associated with a \doxylink{classfccvis_1_1scene_1_1Scene}{fccvis::\+scene::\+\+Scene}.

The class currently contains no additional configuration fields beyond the identity inherited from \doxylink{classfccvis_1_1scene_1_1BaseSessionObject}{fccvis::\+scene::\+\+Base\+Session\+Object}. It provides the intended extension point for future scene configuration, including coloring and other rendering-\/related options.
