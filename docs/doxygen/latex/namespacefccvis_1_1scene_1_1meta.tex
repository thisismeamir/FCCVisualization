\doxysubsection{Detailed Description}
Metadata and graphical primitives for visualization scenes. 

Metadata and configuration objects for visualization scenes.

The {\ttfamily \doxylink{namespacefccvis_1_1scene_1_1meta}{fccvis::\+scene::\+meta}} namespace contains the lightweight configuration objects used to describe how scenes are constructed and displayed.

These objects are primarily metadata rather than rendering objects. They can be composed into higher-\/level objects such as \doxylink{classfccvis_1_1scene_1_1Scene}{fccvis::\+scene::\+\+Scene} and \doxylink{classfccvis_1_1session_1_1SessionOptions}{fccvis::\+session::\+\+Session\+Options}.
