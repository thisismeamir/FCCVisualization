\doxysubsection{Detailed Description}
Represents an FCCVisualization session. 

A \doxylink{classfccvis_1_1session_1_1Session}{Session} is the central object that connects session configuration with loaded event data.

A session consists of:
\begin{DoxyItemize}
\item a name identifying the session;
\item an optional event-\/data file;
\item an optional options/\+configuration file;
\item \doxylink{classfccvis_1_1session_1_1SessionData}{fccvis::\+session::\+\+Session\+Data} containing loaded podio frames;
\item \doxylink{classfccvis_1_1session_1_1SessionOptions}{fccvis::\+session::\+\+Session\+Options} containing visualization configuration.
\end{DoxyItemize}

The session provides the main programmatic interface for discovering available data categories, entries, collections, and collection types.

\begin{DoxyNote}{Note}
Copy construction and copy assignment are disabled. Sessions are movable.
\end{DoxyNote}
