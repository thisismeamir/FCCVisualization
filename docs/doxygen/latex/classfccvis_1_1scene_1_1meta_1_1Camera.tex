\doxysubsection{Detailed Description}
\doxylink{classfccvis_1_1scene_1_1meta_1_1Camera}{Camera} configuration for a visualization scene. 

\doxylink{classfccvis_1_1scene_1_1meta_1_1Camera}{Camera} stores the geometric parameters required to describe a scene\textquotesingle{}s viewpoint.

The object inherits its identifying name from \doxylink{classfccvis_1_1scene_1_1BaseSessionObject}{fccvis::\+scene::\+\+Base\+Session\+Object} and can therefore be referenced as a named session object.
