\doxysubsection{Detailed Description}
A reusable visualization scene. 

A \doxylink{classfccvis_1_1scene_1_1Scene}{Scene} represents a named visualization configuration within an FCCVisualization session. It combines:


\begin{DoxyItemize}
\item a scene name inherited from \doxylink{classfccvis_1_1scene_1_1BaseSessionObject}{Base\+Session\+Object};
\item an optional camera configuration;
\item a collection of visualization filters;
\item scene-\/specific rendering and display options.
\end{DoxyItemize}

A scene can therefore describe how a particular view of event data should be presented without being tied to a specific event.
