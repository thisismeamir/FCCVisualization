\doxysubsection{Detailed Description}
Base class for named objects belonging to a visualization session. 

Provides a common identity mechanism for objects that are part of an FCCVisualization scene or session. Every derived object has a human-\/readable name that can be used to identify and reference it within the visualization configuration.
