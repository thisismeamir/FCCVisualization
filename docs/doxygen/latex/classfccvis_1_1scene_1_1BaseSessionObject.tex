\doxysubsection{Detailed Description}
Base class for named objects in an FCCVisualization session. 

\doxylink{classfccvis_1_1scene_1_1BaseSessionObject}{Base\+Session\+Object} provides a common identity mechanism for objects that participate in a scene or session configuration.

Derived classes inherit a public \doxylink{classfccvis_1_1scene_1_1BaseSessionObject_a694285efaa01ef5f5cb9b0a1fdf04a22}{name} member and can therefore be identified consistently throughout the visualization system.
