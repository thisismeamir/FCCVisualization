\doxysubsection{Detailed Description}
Manages the live ROOT/\+\+TEve representations of session scenes. 

\doxylink{classfccvis_1_1backend_1_1root_1_1RootSceneManager}{Root\+Scene\+Manager} provides the main interface for opening, updating, querying, and closing ROOT representations of abstract \doxylink{classfccvis_1_1scene_1_1Scene}{fccvis::\+scene::\+\+Scene} objects.

The manager holds a non-\/owning reference to an existing \doxylink{classfccvis_1_1session_1_1Session}{fccvis::\+session::\+\+Session}. Abstract scenes are discovered from that session and materialized into \doxylink{classfccvis_1_1backend_1_1root_1_1RootScene}{Root\+Scene} objects when requested.

Multiple open scenes are tracked by their names. Opening an already open scene returns the existing materialization rather than creating a second ROOT representation.
