\doxysubsection{Detailed Description}
ROOT/\+\+TEve materialization of an FCCVisualization scene. 

Defines \doxylink{classfccvis_1_1backend_1_1root_1_1RootScene}{fccvis::\+backend::\+root::\+\+Root\+Scene}, which connects an abstract FCCVisualization scene to its ROOT/\+\+TEve representation.

An abstract \doxylink{classfccvis_1_1scene_1_1Scene}{fccvis::\+scene::\+\+Scene} describes the visualization independently of the rendering backend. Root\+Scene materializes that description into the corresponding ROOT TEve objects, including a {\ttfamily TEve\+Scene} and {\ttfamily TEve\+Viewer}.
