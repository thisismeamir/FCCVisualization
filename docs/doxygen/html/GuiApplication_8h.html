Detailed Description

ROOT GUI application lifecycle management.

Defines the fccvis::gui::GuiApplication class, which owns and manages the ROOT TApplication instance used by the FCCVisualization graphical interface.

The GUI application is associated with an existing fccvis::session::Session and provides the main event loop and termination interface for the graphical application.
