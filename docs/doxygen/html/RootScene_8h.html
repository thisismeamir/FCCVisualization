Detailed Description

ROOT/TEve materialization of an FCCVisualization scene.

Defines fccvis::backend::root::RootScene, which connects an abstract FCCVisualization scene to its ROOT/TEve representation.

An abstract fccvis::scene::Scene describes the visualization independently of the rendering backend. RootScene materializes that description into the corresponding ROOT TEve objects, including a TEveScene and TEveViewer.
