Detailed Description

Metadata and graphical primitives for visualization scenes.

Metadata and configuration objects for visualization scenes.

The fccvis::scene::meta namespace contains the lightweight configuration objects used to describe how scenes are constructed and displayed.

These objects are primarily metadata rather than rendering objects. They can be composed into higher-level objects such as fccvis::scene::Scene and fccvis::session::SessionOptions.

enum class fccvis::scene::meta::Color
strong

Color specification for visualization primitives.

Color provides a backend-independent enumeration of the colors available to scene primitives such as Marker and Line.

In addition to explicit colors, the enumeration provides automatic color modes. The interpretation of automatic modes is performed by the visualization backend.

◆ LayoutKind

enum class fccvis::scene::meta::LayoutKind
strong

Describes the structural role of a node in a scene layout.

A layout is represented as a tree of LayoutNode objects. Each node has one of three structural roles:

  • Pack: contains child nodes arranged according to an orientation.
  • Tab: contains child nodes presented as alternative tab views.
  • Leaf: represents a concrete scene slot.
