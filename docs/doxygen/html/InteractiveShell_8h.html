Detailed Description

Interactive command-line shell for FCCVisualization.

Defines the interactive shell used to inspect and control an FCCVisualization session from the command line.

The shell connects the active session to the ROOT Cling interpreter and provides built-in commands for navigating and controlling visualization scenes.
