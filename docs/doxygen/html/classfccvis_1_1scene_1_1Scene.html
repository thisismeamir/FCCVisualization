Detailed Description

A reusable visualization scene.

A Scene represents a named visualization configuration within an FCCVisualization session. It combines:

  • a scene name inherited from BaseSessionObject;
  • an optional camera configuration;
  • a collection of visualization filters;
  • scene-specific rendering and display options.

A scene can therefore describe how a particular view of event data should be presented without being tied to a specific event.

Camera associated with the scene.

The camera defines the viewpoint from which the scene is displayed.

A shared pointer is used because camera objects may be shared between multiple parts of a session configuration.

std::vector<std::shared_ptr<fccvis::scene::meta::Filter> > fccvis::scene::Scene::filters

Filters applied to the scene.

Filters determine which visualization content is included in or excluded from the scene.

Each filter is shared through a std::shared_ptr so that filter definitions can be reused across scenes.
