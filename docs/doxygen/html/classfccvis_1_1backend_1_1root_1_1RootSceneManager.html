Detailed Description

Manages the live ROOT/TEve representations of session scenes.

RootSceneManager provides the main interface for opening, updating, querying, and closing ROOT representations of abstract fccvis::scene::Scene objects.

The manager holds a non-owning reference to an existing fccvis::session::Session. Abstract scenes are discovered from that session and materialized into RootScene objects when requested.

Multiple open scenes are tracked by their names. Opening an already open scene returns the existing materialization rather than creating a second ROOT representation.
