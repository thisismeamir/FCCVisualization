Detailed Description

Interactive command-line shell for a visualization session.

InteractiveShell provides a command interface for inspecting and controlling an active fccvis::session::Session.

The shell maintains command history, provides built-in commands for scene management, and exposes the active session to the ROOT Cling interpreter.

The shell uses a fccvis::backend::root::RootSceneManager to manage the ROOT-based visualization of scenes.

Note
The Session is referenced but not owned by the shell. The referenced session must remain valid for the lifetime of the InteractiveShell.
