Detailed Description

Session state, input data, and visualization configuration.

Defines the classes used to represent an FCCVisualization session:

  • fccvis::session::SessionOptions stores visualization configuration.
  • fccvis::session::SessionData stores loaded event data.
  • fccvis::session::Session coordinates the session name, data, options, and access to event information.
